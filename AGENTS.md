



# Running command.
Expect that the app is already running by docker compose (`make run` commnad).
Check `compose.yml` to undertand the app structure.
Before run any command check makefile, the commnad can be exist here. Makefile commands have high priority.

## Workers
Before run anything after changes, restart worker also to apply the changes.

## Run test
To run test use `make test` commnad.
In the same time check logs from the app.
